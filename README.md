# Keenetic для MajorDoMo

Модуль интеграции интернет-центров **Keenetic** с MajorDoMo: роутеры, устройства,
подключения, DNS, обновления прошивок и PHP-обработчики событий.

Версия 0.5.2 — переработана под новый интерфейс MajorDoMo (Bootstrap 5 + `md-*`,
Tabler Icons), с исправлениями и новыми разделами.

## Возможности

- несколько роутеров: IP-адрес, KeenDNS-имя, порт;
- доступность роутера, наличие интернета, активный канал (основной/резервный) и внешний IP;
- обновления KeeneticOS: проверка, уведомления, установка из интерфейса;
- перезагрузка и сохранение конфигурации роутера;
- устройства: статус, LAN/Wi-Fi, MAC, IP, трафик, точка доступа, SSID, частота, режим и RSSI;
- общий список устройств со всех роутеров с поиском и фильтрами;
- привязка устройств и подключений к свойствам и методам объектов MajorDoMo;
- отслеживание параметров устройства через класс роутера и метод `track`;
- PHP-обработчики на смену статуса устройства, подключения и интернета;
- управление подключениями (VPN, PPPoE и др.) тумблером без перезагрузки страницы;
- статические DNS-записи (`ip host`) из интерфейса;
- Wake-on-LAN и регистрация устройства на роутере;
- журналы интернета и устройства, отладочный лог DebMes;
- API для скриптов и `callAPI`.

## Требования

- MajorDoMo с новой админкой (Bootstrap 5, дизайн-система `md-*`);
- PHP 8.1+ (проверено на PHP 8.4);
- KeeneticOS 2.13+;
- включённый доступ к RCI (`/rci`) и учётная запись администратора роутера.

## Установка

### Через «Дополнения» (маркет)

1. Откройте **Система → Дополнения**.
2. Найдите модуль в списке или укажите репозиторий
   `https://github.com/SmoKE585/majordomo-keenetic`.
3. Установите и откройте **Устройства → Keenetic**.

### Вручную

Распакуйте архив в корень MajorDoMo, сохранив структуру:

```
modules/keenetic/...
templates/keenetic/...
public/assets/modules/keenetic/...
public/assets/img/modules/keenetic.png
scripts/cycle_keenetic.php
```

Затем откройте модуль в панели — таблицы создадутся автоматически. При
обновлении с версии 0.4 модуль сам добавит недостающие колонки и перенесёт
старый флаг «не проверять обновления».

## Быстрый старт

1. **Добавить роутер**: название, адрес, логин, пароль, период опроса.
2. Модуль проверит авторизацию и создаст класс объектов с именем роутера.
3. Откройте карточку роутера: вкладки «Обзор», «Настройки», «Устройства»,
   «Подключения», «DNS».
4. Для нужного устройства откройте карточку и укажите привязку к объекту
   и/или включите отслеживание.

## Настройки модуля

**Keenetic → Ещё → Настройки модуля**:

- **Отладка DebMes** — подробный журнал запросов в `YYYY-mm-dd_keenetic.log`;
- **Уведомлять о новых прошивках** — уведомление в панели;
- **Проверять обновления прошивок** — ежечасная проверка для всех роутеров;
- **Цикл опроса** — состояние фонового процесса и переход в X-Ray.

У каждого роутера отдельно: период опроса, автоперезагрузка при потере
интернета и отключение проверки обновлений (удобно на канале предварительных
прошивок).

## Обработчики

### Устройство

Переменные: `$status` (1 — в сети, 0 — не в сети), `$device` — данные роутера,
`$router` — запись роутера.

```php
if ($status) {
    say('Телефон ребёнка в сети', 1);
} else {
    say('Телефон ребёнка не в сети', 1);
}
```

### Подключение

Переменные: `$name`, `$state` (1 — подключено), `$connection`, `$router`.

```php
if ($state) {
    say('Соединение ' . $name . ' установлено', 2);
} else {
    say('Соединение ' . $name . ' потеряно', 2);
}
```

### Интернет

Переменные: `$status` (0 — нет, 1 — основной канал, 2+ — резервный),
`$inet`, `$router`.

```php
if ($status === 0) {
    say('Интернет пропал', 2);
} elseif ($status > 1) {
    say('Интернет через резервный канал ' . ($status - 1), 2);
}
```

Код проверяется на синтаксис перед сохранением. Ошибки выполнения попадают в
«Ошибки системы» с контекстом.

## Отслеживание

При включении отслеживания в классе роутера создаётся объект с именем
устройства, а на каждом опросе вызывается метод `track` с параметрами:

| Параметр | Значение |
| --- | --- |
| `UPTIME` | время в сети, сек |
| `RXBYTES`, `TXBYTES` | трафик |
| `ROUTER` | точка доступа или роутер |
| `NET` | SSID |
| `FREQ` | 2.4 или 5 ГГц |
| `WIFI_MODE` | стандарт, MIMO, частота, скорость |
| `RSSI` | уровень сигнала |

Стандартный метод раскладывает параметры по свойствам класса. Его можно
заменить своим методом объекта — это сокращает число записей в БД.

> Каждый опрос пишет до 8 свойств на отслеживаемое устройство. Включайте
> отслеживание только там, где оно действительно нужно.

## API

```php
include_once(DIR_MODULES . 'keenetic/keenetic.class.php');
$keenetic = new keenetic();

// Произвольная команда RCI: ID/адрес, тело команды, сохранить конфигурацию
$result = $keenetic->command('1', '{"show": {"ip": {"hotspot": {}}}}', true);

// Перезагрузка и Wake-on-LAN
$keenetic->reboot('1');
$keenetic->wol('68:72:c3:56:42:81');

// Управление подключением: 0 — выключить, 1 — включить, 2 — переключить
$keenetic->changeConnection('Wireguard0', 2);
```

Через API MajorDoMo:

```
/api/module/keenetic?id=1&path=show/interface&data=
```

Параметр `id` — ID роутера или его адрес.

## Служебные URL

- `/panel/keenetic.html` — список роутеров;
- `/panel/keenetic.html?view_mode=edit_keenetic_routers&id=1` — карточка роутера;
- `&tab=data|cnct|dns|settings` — вкладки;
- `?view_mode=devices` — все устройства;
- `?view_mode=info_keenetic_devices&id=1` — карточка устройства;
- `?view_mode=settings` — настройки модуля;
- `?view_mode=show_help` — справка.

Старые ссылки с `data_source=keenetic_routers` и прежними `view_mode`
продолжают открываться.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Роутер недоступен | адрес, HTTP/HTTPS, доступность веб-интерфейса |
| Ошибка авторизации | логин и пароль; при смене пароля введите его заново |
| Нет устройств | период опроса не 0, состояние цикла, журнал интернета |
| Нет уведомлений о прошивке | «Проверять обновления» в настройках и у роутера |
| Статус устройства «мигает» | увеличьте период опроса или включите отслеживание |

Подробный лог: включите «Отладка DebMes» и смотрите
`YYYY-mm-dd_keenetic.log` в каталоге логов MajorDoMo.

## Разработка

- PHP: `php -l modules/keenetic/keenetic.class.php`;
- JS: `node --check public/assets/modules/keenetic/keenetic.js`;
- шаблоны — jTemplate (`[#...#]`), без PHP внутри;
- стили — только токены `--md-ui-*`, тёмная тема и 390 px обязательны.

Проверки без базы данных:

```bash
php modules/keenetic/tests/helpers_test.php
php modules/keenetic/tests/class_logic_test.php
MAJORDOMO_ROOT=/path/to/majordomo php modules/keenetic/tests/template_smoke.php
```

`modules/keenetic/tests/template_smoke.php` рендерит все страницы модуля через
настоящий `jTemplate` из MajorDoMo и проверяет, что в разметке не осталось
шаблонных тегов. С ключом `--preview-dir=...` он сохраняет статические
HTML-страницы для просмотра вёрстки без запуска MajorDoMo.
