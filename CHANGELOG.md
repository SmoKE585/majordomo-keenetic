# Changelog

## 0.5.3 — 2026-10-23

- Исправлена ложная ошибка `Syntax error in code … sh: python: not found`: обработчики устройств, подключений и интернета теперь проверяются как PHP, без автоопределения Python. Короткий обработчик по умолчанию (`if($status){ … }`) больше не считается Python-кодом.
- Проверка синтаксиса кэшируется на время процесса, чтобы не запускать `php -l` при каждом событии.
- Ошибки разбора из `eval()` попадают в «Ошибки системы» как синтаксические, а не как ошибки выполнения.

## 0.5.2 — 2026-10-21

- Исправлены выпадающие меню действий в таблицах: меню больше не обрезается краем таблицы. В новом ядре используется общий portal-механизм `.md-table__scroll`, в старом — резервная реализация модуля.
- Обновлён cache-bust ассетов модуля, чтобы браузер не держал старые `keenetic.css`/`keenetic.js`.
- Убрано `contain: paint` у прокручиваемой таблицы, из-за которого меню и подсказки обрезались.

## 0.5 — 2026-10-21

Переработка под новый интерфейс MajorDoMo (Bootstrap 5, `md-*`, Tabler Icons).

### Интерфейс

- список роутеров: hero, KPI, таблица с поиском, фильтрами и сортировкой;
- карточка роутера с вкладками «Обзор», «Настройки», «Устройства», «Подключения», «DNS»;
- отдельная страница «Все устройства» с фильтром по роутеру, статусу, типу и отслеживанию;
- карточка устройства: основные данные, Wi-Fi и RSSI, привязка, отслеживание, скрипт и журнал;
- страница настроек модуля и переработанная справка;
- ассеты модуля вынесены в `public/assets/modules/keenetic/`;
- иконка модуля перенесена в `public/assets/img/modules/keenetic.png`;
- тёмная тема и мобильная вёрстка.

### Новые возможности

- установка обновления прошивки, перезагрузка и сохранение конфигурации из интерфейса;
- принудительный опрос роутера без ожидания цикла;
- Wake-on-LAN и регистрация устройства из карточки;
- управление привязками устройств и подключений в одном месте;
- отображение активного канала и внешнего IP;
- переключатель «не проверять обновления» вынесен в отдельное поле `NO_UPDATE`;
- настройки уведомлений о прошивках и глобальной проверки обновлений;
- обработчик смены подключения и статуса интернета с расширенным набором переменных.

### Исправления

- пароли с произвольными символами теперь сохраняются в новом формате (`b64:` + обратимое шифрование), старые пароли читаются;
- исправлена повторная авторизация при истёкших cookie;
- пустой ответ роутера больше не удаляет все устройства и подключения;
- корректно обрабатываются несколько `Set-Cookie` и заголовки challenge;
- исправлены ошибки в карточке устройства (запись в `$out`, сохранение кода при синтаксической ошибке, отображение хранения);
- устранены SQL-инъекции в API и обработчиках связей, добавлена проверка авторизации для AJAX-переключателя;
- исправлены ссылки глобального поиска и удаление роутера с привязками;
- схема БД расширяется автоматически: `NO_UPDATE`, `HREF_FW`, длина `COOKIES`, `PASSWORD`, `MODEL`, `FIRMWARE`, `SERIAL`, тип `AUTO_REBOOT`/`REQ_PERIOD`;
- исправлены `SHOW COLUMNS`/миграции и совместимость с PHP 8.4.

### Структура

- логика разбита на `keenetic.class.php` и `keenetic_helpers.inc.php`;
- удалены неиспользуемые include-файлы и старые шаблоны;
- добавлены тесты `modules/keenetic/tests/helpers_test.php`, `modules/keenetic/tests/class_logic_test.php`, `modules/keenetic/tests/template_smoke.php`;
- добавлен `.gitignore`, IDE-метаданные исключены из репозитория.
